## 当前结论

可先做控制板、遥控输入、无力输出及被动反馈检查。
带动力CALI和后续闭环联动前，应先处理下面两个P1问题。

### P1：保存标定前，Yaw零输出未组成完整CAN帧

- 位置：`Modules/HFUT-WDR/Gimbal/gimbal.cpp:205-207`。
- CAN3的两个Yaw（反馈0x205/0x206）与拨弹（反馈0x207）共用控制帧0x1FF。
  `RMMotor::PackAndSend` 要等三个已注册槽位均更新才提交整帧。
- CALI结束时只调用 `yaw_.Send()`，拨弹槽位在 `ApplyCalibration` 同步写库返回后才更新。
  因而调用发送函数不等于零输出已经发到总线。
- 当前源码离线复现：进入 `Database::Set` 时，最后发送的指令为
  `inner=-8000, outer=0, trigger=0`；写库返回后才变为 `inner=0, outer=0`。
  实机Flash阻塞持续时间和电机动作尚未测量。
- 修复验收：在可能阻塞的保存开始前，完成停止状态更新和整组输出提交；
  测试必须包含同组拨弹实例，并在数据库写入入口检查已发送的整帧。
  实机还需确认零帧真正发出，而非仅进入软件发送队列。

### P1：IMU首帧到达后，断流不退出云台闭环

- 位置：`Modules/HFUT-WDR/Gimbal/gimbal.cpp:361-365`。
- `board_seen_` / `dm_seen_` 只判断曾经收到数据，后续没有按姿态时间戳判定断流。
  电机和遥控仍在线时，会继续使用缓存的角度、角速度；CALI的低速端点判定同样受影响。
- 当前源码离线复现：仅停止DM IMU发布1000ms，板载IMU、遥控、电机反馈继续刷新，
  实际模式仍为 `ABSOLUTE_ANGLE`，`waiting_for_enable=false`，最后发送的
  `inner=30000, outer=0`。这是指令输出证据，不是实机运动证据。
- 修复验收：对当前模式必需的IMU按真实数据时间判定超时；失效时停止相关闭环并落实整车联锁。
  CALI中止后不自动重扫。覆盖断流、恢复和校准中断即可，无需扩展数值边界校验。

## 上车顺序与通过条件

每一步不满足通过条件就停在该步，先定位输入、实际模式、反馈和发送输出。
首次检查清空弹路、架空车轮，准备独立动力断电；观察运行数据时避免带动力断点暂停。

| 步骤 | 操作 | 通过条件 |
| --- | --- | --- |
| 1. 确认固件 | 机构动力断开，确认生成头来自整车YAML，构建并烧录校验。保留数据库扇区，记录实际ELF和版本。 | 烧录校验成功；持续运行无异常复位，任务、IMU数据持续更新。 |
| 2. 遥控与无力 | SW0/SW1/SW2/SW3均上拨，摇杆回中、旋钮转到最小。观察 `i6x_input`；机构动力仍断开时逐一核对拨杆和通道。 | 物理上/中/下对应+1/0/-1；通道方向、回中正确，旋钮最小对应wz=0；SW2上位实际为RELAX。无力时拨SW1不留下摩擦轮开启请求。 |
| 3. 被动反馈 | 保持SW2上位，接通需要检查的驱动器电源；逐总线确认反馈。手动轻转可自由转动的机构，核对编码器、IMU方向和DM4310电机零位。 | 设备稳定在线，反馈轴与机构对应；无力时Yaw/轮电机零驱动、Pitch保留使能但MIT刚度/阻尼/力矩均为零。摩擦轮若尚有惯性，允许现有闭环制动过程，不能把所有非零制动电流判错。 |
| 4. Yaw校准与持久化 | 两个P1修复并回归后，先验证校准时的遥控失联中止。再做完整手势校准，保留Yaw机械扫描空间，底盘和发射隔离动力。 | 外Yaw正/负、内Yaw正/负依次扫描；Pitch不扫描，底盘/发射停止。完成后回RELAX，`calibration_complete=true`、`calibration_saved=true`、`calibration_failed=false`，保持手势不重扫。断电重启后零位及限位与保存前一致。 |
| 5. 云台遥控 | SW3上位、SW0上位、SW1上位，发射动力继续隔离；SW2中位，从很小的Yaw/Pitch输入开始。先小角度，再逐步检查限位。 | 方向正确、无自激或持续顶限位；SW2上位退出驱动。分别验证遥控失联、Yaw失联、IMU断流处理；恢复前先将SW2上拨。 |
| 6. 架空底盘 | 云台检查通过后，SW2中位、SW3下位、旋钮最小。小幅前后、横移，再小幅增加旋钮。 | 四轮方向与反馈对应；回中且旋钮最小时停止运动请求；SW3上位停止底盘，SW2上位或遥控失联联动停止。验证任一轮失联时整底盘无力。 |
| 7. 空载发射 | SW3上位、SW2中位、SW0上位。SW1下拨一次开启摩擦轮，再回上位；到速后短暂SW0下拨测试拨弹，再回上位。最后SW1再下拨关闭。 | 顺序为READY_FRIC→READY→BULLET→READY→STOP；不到速不拨弹。SW0回上位只停拨弹，SW1关闭摩擦轮。SW2上位/遥控失联停止发射；返回OP后必须重新触发摩擦轮开启。 |
| 8. 落地低速联动 | 前面全部通过，再落地小范围测试：先平移，后低速旋转，再云台联动；先保持发射关闭。重复停止与恢复检查。 | 无明显振荡、方向错误、掉线或功率异常；停止路径均有效，恢复行为符合当前拨杆。通过后再开展后续完整整车测试。 |

### 校准操作的特别说明

- 入口是SW2上位、SW0下位，使用映射/交换后的四通道：
  先保持 `(-,-,+,-)`，再保持 `(+,+,-,+)`，各分量严格超过统一宏门限±550，
  各阶段连续超过2秒，第二阶段在20秒选择窗口内完成。
  先在断机构动力阶段核对通道，避免把手势方向猜反。
- 校准接受后，释放摇杆仍会扫描；SW2本来就在上位，继续上拨不能中止。
  异常时使用独立动力断电；遥控失联中止路径应先验证。
- Pitch使用DM4310自身零位，不做Pitch端点扫描或电机设零。
- `calibration_saved` 表示本次运行写入成功。重启加载不把此标志设为true，
  所以持久化验收应比较重启前后的 `calibration` 内容，不能只看这个布尔值。
- 第一阶段手势成功后有间歇提示，进入CALI后改为持续提示；选择超时、失联或结束时关闭。

### 速度、恢复及AUTO范围

- 旋钮映射0～12 rad/s，中位约6 rad/s，因此首次上电必须放最小，不能按“回中即停止”操作。
- 普通遥控/电机故障恢复后，模式会跟随当前拨杆恢复，不要求重新使能边沿。
  断连测试后恢复连接前，先上拨SW2；不能把“已经失联”当作持续的停止锁存。
- 本整车YAML尚未实例化上位机接收模块。SW2下位无有效上位机数据时应保持无力，
  不能据此验收完整AUTO通信、导航或自瞄链路。
  后续接入后再验证STOP/SCAN/AIM、PC超时、OP/AUTO切换以及wz只取遥控旋钮。
